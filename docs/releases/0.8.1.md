# PokeMMO Companion v0.8.1 Alpha

This update improves Storyline reliability, adds an Alphapedia reporting link and makes floating tools easier to use at smaller window sizes.

### Storyline and planning

- **Storyline and Breeding Plan.** Scroll through short Storyline popouts and keep the next objective in sync with your saved checkmarks. Breeding Plan edits persist through autosave and navigation.
### Encounters and references

- **Home and Live.** Encounter cards share colored estimated-time pills. Green shows time remaining for a likely-active report, amber marks uncertain timing and red marks an elapsed estimate. Repeat sightings use the original window. Current encounter and roamer art follows your motion settings. The rotation calendar stays static.
- **Reports and Phenomena.** [Alphapedia by FlaProGmr and LordDuskk](https://alpha.pokemmotools.org/) provides the optional Alpha and Swarm feeds. [Report via Alphapedia](https://alpha.pokemmotools.org/help#tab-publish) opens the official publishing guide. The Phenomena view links directly to [the Phenomena instructions](https://alpha.pokemmotools.org/help#publish-pheno-panel). Companion keeps received reports and incoming notifications in the app. The expanded offline Unova Phenomena reference distinguishes documented spots from area-level reports. Thanks to MaToRiuKo and yuisigamy for the multilingual field reference.
- **Seasonal reference.** The app supports signed seasonal definitions for future data updates. The bundled catalog is empty.

### Floating tools

- The 17-type matrix adapts to its window, keeps Full Chart or Focus across modes and offers horizontal and vertical column headers.

## Download and upgrade

| Windows x86-64 | Linux x86-64 |
| --- | --- |
| Download the [Windows portable ZIP](https://github.com/haqzo/PokeMMO-Companion/releases/download/v0.8.1/PokeMMO-Companion-0.8.1-windows-x86_64.zip), extract it to a fresh folder and open `pokemmo-companion.exe`. | Download the [Linux AppImage](https://github.com/haqzo/PokeMMO-Companion/releases/download/v0.8.1/PokeMMO-Companion-0.8.1-x86_64.AppImage), mark it executable and open it. Extraction mode is available if FUSE is unavailable. |

Verify your package against [SHA256SUMS](https://github.com/haqzo/PokeMMO-Companion/releases/download/v0.8.1/SHA256SUMS) and its [Ed25519 signature](https://github.com/haqzo/PokeMMO-Companion/releases/download/v0.8.1/SHA256SUMS.sig). [Build provenance](https://github.com/haqzo/PokeMMO-Companion/releases/download/v0.8.1/build-provenance.json) Quit Companion fully before replacing application files. The app stores personal data in a separate profile.

Portable ZIP backups and JSON exports exclude local report history. A SQLite migration safety copy preserves it. Merge keeps current settings, and Replace restores archived settings and supported records. Both keep the destination profile’s report history.

## Compatibility verification

Official builds use Ubuntu 22.04 and Windows Server 2025 on x86-64. The Linux package enforces a maximum glibc requirement of 2.35. Candidate QA exercised native Qt on KDE Wayland and XWayland using AppImage extraction and verified upgrade from the published 0.8.0 packages on both platforms with disposable profiles. Interactive Windows 10 and 11 desktop verification remains open.

## Known limitations

Window pinning, positioning and opacity depend on Wayland compositor support. At very small sizes the full Type Chart remains scrollable. Phenomena references keep their source and location precision labels. Elapsed estimates do not verify a despawn.
