# PokeMMO Companion 0.8.0 Alpha

PokeMMO Companion is an unofficial desktop app you can keep open next to PokeMMO. Look up where to find a Pokémon, check an item or move, follow a walkthrough, or keep a calculator in a floating window.

## What’s included

- Browse the **Pokédex** with animated normal and shiny sprites, find encounters in **Location Explorer**, and look up items, moves and type matchups. The bundled reference works offline without ROMs or dumps.
- Follow walkthroughs for **Kanto, Johto, Hoenn, Sinnoh and Unova**. Use storyline runs to track progress separately for each character.
- Look up **Phenomena**, legendary Pokémon and **Altering Cave** information. Optional community **Alpha & Swarm** reports need a connection. Altering Cave provides reference information and a link to the community tracker.
- Keep **Notes**, record catches in **My Pokémon**, organize a **Shiny Showcase**, plan teams in **Team Builder**, and use breeding tools, calculators and timers while you play.
- Open supported tools in resizable floating windows with compact, standard and expanded layouts. Choose English, Spanish or Simplified Chinese, customize themes, text size and layout, and select a Balanced, Lightweight, Full quality or Custom performance profile.

## Install

- **Linux x86-64.** Download `PokeMMO-Companion-0.8.0-x86_64.AppImage` from this release. Make it executable in your file manager or run `chmod +x PokeMMO-Companion-0.8.0-x86_64.AppImage`, then open it. If FUSE is unavailable, run `./PokeMMO-Companion-0.8.0-x86_64.AppImage --appimage-extract-and-run`.
- **Windows x86-64.** Download `PokeMMO-Companion-0.8.0-windows-x86_64.zip`, choose **Extract All**, then run `pokemmo-companion.exe` inside the extracted `pokemmo-companion` folder. Keep the extracted files together. The ZIP includes the Python and Qt runtimes.
- **Checksums.** Compare your download’s SHA-256 with the matching entry in `SHA256SUMS` under Assets. On Linux use `sha256sum <filename>`. On Windows use `Get-FileHash -Algorithm SHA256 <filename>` in PowerShell.

## Back up and update

Open **Settings → Backup & recovery**, make a complete backup ZIP and save a copy away from the app. Quit Companion, including from the tray, before replacing the AppImage or opening a new Windows extraction. Your profile is stored separately under `~/.local/share/pokemmo-companion` on Linux or `%APPDATA%\PokeMMO-Companion` on Windows by default. To recover, select the backup under **Backup & recovery**, preview it, then choose **Merge** or **Replace**. Companion makes a safety copy before restoring.

**Settings → Updates** defaults to **Alpha, beta & prereleases** in 0.8.0 when you have no saved channel. Companion keeps your explicit choice. **Stable** shows regular stable releases only. The app verifies the signed checksum and package when using its verified download. Install updates manually.

## Alpha testing

This is public alpha software, released on 25 November 2026. Both official x86-64 packages passed automated verification in the [release build](https://github.com/haqzo/PokeMMO-Companion/actions/runs/45708065896). The final Linux AppImage was tested on CachyOS KDE via extraction, including live reports and official news connectivity. Direct Linux FUSE launch and interactive Windows 10 and 11 desktop testing remain unverified. If automatic AppImage extraction fails, try `TMPDIR="$(mktemp -d)" ./PokeMMO-Companion-0.8.0-x86_64.AppImage --appimage-extract-and-run` or extract manually and run AppRun. Try your usual offline lookups, floating tools and app restart, and back up any personal data you want to keep. For always-on-top and saved window positions on KDE, select **XWayland** in **Settings → Windows & popouts → Window backend** and restart. Native Wayland does not provide those controls. Reference listings may differ from current in-game availability, and Spanish and Simplified Chinese terminology is still being reviewed.
