# PokeMMO Companion 0.8.0 Alpha

PokeMMO Companion is an unofficial desktop app you can keep open next to PokeMMO. Look up where to find a Pokémon, check an item or move, follow a walkthrough, or keep a calculator in a floating window.

## What’s included

- Browse the Pokédex with normal and shiny sprites, search encounter locations, and look up items, moves and type matchups. Regional maps and the built-in reference work offline. You can start without importing ROMs or dumps.
- Follow walkthroughs for Kanto, Johto, Hoenn, Sinnoh and Unova. Track your progress and keep your teams, notes and timers together. Optional community Alpha and Swarm reports need a network connection. The Unova Phenomena reference works offline.
- Open supported tools in separate, resizable windows with compact, standard and expanded layouts. Choose English, Spanish or Simplified Chinese, customize themes, text size and layout, and choose a Balanced, Lightweight, Full quality or Custom performance profile.

## Install

- **Linux x86-64.** Download `PokeMMO-Companion-0.8.0-x86_64.AppImage` from this release. Make it executable in your file manager or run `chmod +x PokeMMO-Companion-0.8.0-x86_64.AppImage`, then open it. If FUSE is unavailable, run `./PokeMMO-Companion-0.8.0-x86_64.AppImage --appimage-extract-and-run`.
- **Windows x86-64.** Download `PokeMMO-Companion-0.8.0-windows-x86_64.zip`, choose **Extract All**, then run `pokemmo-companion.exe` inside the extracted `pokemmo-companion` folder. Keep the extracted files together. The ZIP includes the Python and Qt runtimes.
- **Checksums.** Compare your download’s SHA-256 with the matching entry in `SHA256SUMS` under Assets. On Linux use `sha256sum <filename>`. On Windows use `Get-FileHash -Algorithm SHA256 <filename>` in PowerShell.

## Back up and update

Open **Settings → Backup & recovery**, make a complete backup ZIP and save a copy away from the app. Quit Companion, including from the tray, before replacing the AppImage or opening a new Windows extraction. Your profile is stored separately under `~/.local/share/pokemmo-companion` on Linux or `%APPDATA%\PokeMMO-Companion` on Windows by default. To recover, select the backup under **Backup & recovery**, preview it, then choose **Merge** or **Replace**. Companion makes a safety copy before restoring.

To check for later alpha and beta builds, select the prerelease channel under **Settings → Updates**. Stable shows regular releases. Updates are installed manually.

## Alpha testing

Try the tools you normally use, including offline lookups, floating windows and quitting and reopening the app. Back up any personal data you want to keep. Linux behavior varies by distribution and desktop. For always-on-top and saved window positions on KDE, select **XWayland** in **Settings → Windows & popouts → Window backend** and restart. Native Wayland does not provide those controls. Reference listings may differ from current in-game availability, and Spanish and Simplified Chinese terminology is still being reviewed.

Report bugs in the [Companion community Discord](https://discord.gg/5Wbh28M3gu). Include the Companion version, OS and desktop, tool, steps to reproduce, and expected and actual behavior. For translations, include the selected language, exact wording, page or guide chapter, suggested correction and a screenshot if helpful. Remove personal information before sharing diagnostics or screenshots.
